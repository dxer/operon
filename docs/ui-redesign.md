# 界面重新设计：方案

> 目标不是「更好看」，是**看起来像一家公司做的**。大厂产品和业余作品最大的差别不在配色，
> 在**约束**：字号就那几档、间距就那几个数、描边就一种粗细、强调色只出现一次。

## 0. 结论

能美化，而且**不需要推翻重来**。现在的基座是对的：

- 主题已经是一套有出处的体系（Fluent 中性阶梯 + Edge 蓝 `#0078D4`），不是随手挑的颜色
- 结构已经是大厂结构（地址栏即唯一导航、智能体入口在地址栏左侧、底部工具条、chrome 自动隐藏）

真正的问题是**没有设计令牌**——同一个意思在不同文件里用了不同的数字。所以方案是
「保留骨架，立下规矩，然后按规矩把每一屏重画一遍」。

## 1. 诊断（数字来自 `grep`，不是印象）

| 现象 | 数据 | 后果 |
|---|---|---|
| 字号没有阶梯 | **22 种**字号，其中 10.5/11/11.5/12/12.5/13/13.5/14/14.5/15/15.5/16 十几档只差 0.5–1 | 每一处都「稍微不一样」，整体读起来是噪点 |
| 正文太小 | 11–12sp 出现 **146 次**，多数没设行高（默认 ≈1.2） | 中文在这个尺寸+行高下是「挤」，不是「紧凑」 |
| 圆角没有档位 | **18 种**半径（2/4/5/6/7/8/9/10/12/13/14/16/17/18/20/21/24/27） | 卡片之间圆角不一致，亲和感直接掉一档 |
| 墨水靠 opacity 现拼 | `Colors.white38`/`black38` 等 **44 处**，另有 `withValues(alpha:)` 一大把 | 暗色下 `white38` 在 `#292929` 上对比度约 4.0:1，11sp 正文达不到 AA |
| 按钮有 5 套 | `TextButton` 52 / `ElevatedButton` 16 / `InkWell` 11 / `OutlinedButton` 9 / `FilledButton` 5 | 同一屏里「主要动作」长三种样子 |
| 语义色被当装饰 | 上一批我把「快捷指令」行图标设成了 `warningOf`（橙） | 橙=警告，用在功能入口上，语义贬值 |
| 快捷图标是假的 | `_buildShortcutIcon` 里硬编码 Google 蓝、bili 蓝、`W` 衬线体 | 这是「AI 做的 App」最明显的信号 |
| 全站没有 favicon | `grep -r favicon lib/` → 0 处 | 标签页、历史、快捷网址全是字母块 |

首页另外还有两处：

- `OPERON` 用 `w900` + `letterSpacing 8`，下面跟一行 9sp、`letterSpacing 2.4` 的全大写 slogan。
  首屏最亮的元素是**自己的名字**，而不是输入框。Chrome、Edge、Safari 的首页都不是这样。
- 品牌方块是「玻璃卡片」（白色 6% 底 + 8% 描边）包一个字母标 —— 这是模板化设计的通用句式。

## 2. 设计令牌（要写进 `AppTheme`，全站只准用这些）

### 2.1 字号 / 行高（7 级）

| 用途 | 字号 | 行高 | 字重 | 现在 |
|---|---|---|---|---|
| display（仅首页品牌） | 28 | 34 | 600 | 28 / 900 |
| title（页面标题、面板标题） | 20 | 26 | 600 | 17–20 混用 |
| headline（卡片标题、行标题） | 17 | 24 | 600 | 15–18 混用 |
| body（正文、输入框、按钮） | 15 | 22 | 400 | 12–14 |
| label（次要标签、元信息） | 13 | 18 | 500 | 10.5–13 |
| caption（步骤、时间、域名） | 12 | 16 | 400 | 10.5–12 |
| micro（角标、<=4 字） | 11 | 14 | 600 | 9–10.5 |

硬规则：**正文 15 起，正文行高 1.5 起**。中文在 1.2 行高下永远显得廉价。

### 2.2 间距（4 基数，只准 4 / 8 / 12 / 16 / 20 / 24 / 32）

卡片内边距 16，页面左右边距 16，行高 56，图标点击区 44–48，分组之间 24。禁止 5/7/9/14/18。

### 2.3 圆角（5 档）

| 档 | 值 | 用在哪 |
|---|---|---|
| chip | 8 | 标签、代码块、小按钮 |
| icon | 13 | 网站图标块 |
| card | 16 | 卡片、输入框外框 |
| sheet | 20 | 面板、弹窗 |
| pill | 999 | 地址栏、搜索框、输入框 |

### 2.4 墨水（3 档，写死不用 opacity 现拼）

- `ink` 100%：`#F3F2F1` / `#201F1E`
- `ink2` 70%：次要说明
- `ink3` 55%：元信息、占位符

同时给 `ink3` 做暗色下限：不低于 `rgba(255,255,255,.55)`（≈4.6:1），现在 `white38` 是不合格的。

### 2.5 描边 / 阴影 / 动效

- 描边统一 **1px**（现在是 0.8，在 2.75x 屏上会被取整成忽粗忽细），颜色 `rgba(255,255,255,.09)` / `rgba(0,0,0,.08)`
- 阴影**只给浮层**（面板顶部、弹窗），页面内容区一律不投影
- 动效 120ms（点击反馈）/ 200ms（展开）/ 320ms（页面），统一 `easeOutCubic`；面板用 `spring` 进、`easeIn` 出

### 2.6 颜色

保留 Edge 蓝作为**唯一强调色**，但补一个它在 UI 里缺的东西：**tint 面**
（`primary` 10–14% 铺底，用于选中态、智能体气泡、运行中图标底）。现在蓝色只出现在文字上，
所以「激活」读起来像「链接」。

语义色回到三个位置：状态条（运行/失败）、步骤结果（成功/失败）、危险确认。
**其他地方一律不用**（包括设置页图标）。

## 3. 逐屏改造

### 3.1 起始页

| 现在 | 改成 | 为什么 |
|---|---|---|
| 54×54 玻璃方块 + `OPERON` w900 + 全大写 slogan | 30px 标记 + `Operon` 17sp w600，slogan 删除 | 首屏的视觉重量应该给输入框 |
| 搜索框 44 高、方角 12 | 48 高、药丸、左端放放大镜 | 药丸是「可以输入」的通用语汇 |
| 快捷网址：硬编码品牌色的字母块 | 站点 favicon（`getFavicon()`）+ 13 圆角；无 favicon 才回落字母，底色 `ink` 8% | 真图标才有「这个 App 认识网络」的感觉 |
| 快捷网址 4 列 aspect 0.8 | 4 列，图标 46 + 标签 11sp 单行省略 | 现在标签会换行，网格高度不齐 |
| — | 常用区加一行「最近访问」 | 首页是导航页，空的比错的好 |

### 3.2 地址栏 + 工具条

| 现在 | 改成 | 为什么 |
|---|---|---|
| pill 44、URL 12sp | 48 高、URL 15sp；**host 加粗、path 变 ink3** | 用户看地址时找的是「我在哪个站」，不是完整 URL |
| 进度条贴在 pill 下沿外 | 2px 收进 pill 内底部，圆角随 pill | 现在像一根多余的线 |
| 左锁标 12sp | 锁标 13 + 只在 https 显示，http 显示「不安全」文字 | 安全状态应该能读，不是猜 |
| 工具条 5 个图标挤在一起 | 4 个主动作 + `⋯`；点击区 44；标签页角标放数字 | 底部栏是最高频目标，不能试探 |
| 智能体入口 40 圆 | 40 圆 + tint 底；运行中改成边框呼吸 | 和 §2.6 的 tint 面统一 |

### 3.3 智能体面板

| 现在 | 改成 | 为什么 |
|---|---|---|
| 三段各自带 padding，header 会随滚动走 | header 固定（标题 + 状态点 + ✕）、中间滚动、composer 固定 | 面板是一个「应用内应用」，需要自己的框架 |
| 步骤是「一卡一次调用」的列表 | **左侧时间线**：圆点（思考空心 / 动作实心 / 结果勾）+ 竖线 | 一卡一次调用看不出顺序，时间线一眼看出「到第几步了」 |
| 结果条：复制/分享/日志 pill + token 文字 | 一行：复制 / 分享 / 再跑一次 + 右端 `12 步 · 8.4k token` | 按钮平级，元信息右对齐 |
| 运行中的最后一步没有状态 | 最后一步带 shimmer 骨架 | 「在跑」和「卡住」必须一眼可分 |
| 用户目标是一段灰底文字 | 右对齐气泡 + tint 底 | 对话式输入，回看时能分清谁说的 |

### 3.4 设置页

- 行高统一 56，左侧图标槽固定 40 宽（图标居中），右侧值 13sp `ink2` + `chevron` 16
- 分组标题 13sp w600 `ink2`，与上一组间距 24
- 危险操作单独成组，红色文字，不与普通开关同卡
- 「快捷指令」图标从 `warningOf` 改回 `primaryOf`（语义修正）

### 3.5 历史 / 标签页 / 快捷指令列表

统一一个 `OperonListRow`（favicon + 标题 17 + 副标题 12 + 尾部动作），三处共用。
历史按「今天 / 昨天 / 更早」分组；标签页卡显示 favicon + 两行标题 + 域名，关闭热区 44。

### 3.6 确认卡 / 状态条

- 确认卡固定三段：**发生了什么**（动词 + 目标，15sp）→ **影响**（一句话，13sp ink2）→ 两个按钮
- 状态条把 4 个按钮收成 2 个（打开 / 停止），审阅在面板里做

## 4. 参考的是哪家的哪一处

| 参考 | 学的是什么 |
|---|---|
| Microsoft Edge（Fluent） | 中性灰阶梯、`#0078D4`、紧凑 chrome、0 高度 AppBar |

## 6. 明确不做

- **不换字体**：中文正文字体包 15MB 起，收益是「更好看一点」，代价是安装包翻倍
- **不做玻璃拟态 / 渐变光晕 / 发光描边**：这是 2021 年的模板语言，也是 AI 作品的标志
- **不改信息架构**：地址栏即导航、底部工具条、面板三段——这三个是对的，重画不重排
- **不加动效**：只在「必须有反馈」的地方（点击、展开、进度）；动效是调味，不是设计
- **不做主题商店**：一套深色一套浅色，做透

已做（工作区未提交）：

**起始页** `start_page_view.dart`
- 品牌区：54 玻璃方块 + `OPERON` w900 + letterSpacing 8 + 全大写 slogan → 30 tint 方块 + `Operon` 17sp w600。**首屏最亮的像素还给了输入框。**
- 搜索框 54 → 48，药丸，去掉投影（页面上不浮东西）。
- 新增「常用」分组标题。
- 快捷网址：品牌色硬编码（Google 蓝 / bili 蓝 / 衬线 W / 黑底 X）→ 单一中性字母标；方块 50→46、圆角 16→13、**去掉描边和投影**（十来个投影小块会抢走搜索框的注意力）。

**地址栏** `browser_controls.dart`
- pill 46 → 48，URL 14 → 15sp。
- **两种状态**：不编辑时画 `host 加粗 + 之后置灰`（Chrome 的做法），编辑时是普通输入框。输入框始终挂着（不编辑时 opacity 0），所以光标、选区、监听器、无障碍节点全都照旧，点一下就进入编辑。
- 进度条从 pill 外面挪进 pill 内部底部，加载时行高不再跳。
- AI 入口：三色渐变（绿→蓝→橙）→ accent tint + accent 图标。渐变是装饰，tint 是控件；而且 tint 和全站「选中」用的是同一个。
- 速读按钮从「第二个 sparkle」改成文档图标——两个 sparkle 挨在一起等于同一个按钮出现两次。

**底部工具条** `bottom_toolbar.dart`：高 52 → 56，描边 0.6 → 1（0.6 在 2.75x 屏上会被取整成忽粗忽细），标签页角标字号入档，菜单页的 24/14 半径、`Colors.white24` 一类的临时灰全部换成令牌。

**守卫测试** `test/design_system_test.dart`（9 个）：读源码，限定已迁移文件只能使用阶梯内的字号与圆角，且不得出现 `Colors.white38` 这类按不透明度命名的灰。文件是**白名单**式的——没迁移的页面不参与，否则测试会因为「还没做的事」一直红着，然后被人关掉。

## 10. P2–P4 落地记录（同一次完成）

### 10.1 智能体面板

**固定框架** — 拖动条、标题行、状态行、进度条从滚动区搬到外面；`Column` 改成 `[frame][滚动区][composer]`。以前跑长任务时，关闭按钮和安全模式开关会跟着内容滚走，正好是运行中最想找的两个东西。

**时间线** — 步骤从「一卡一次调用的列表」改成**左侧竖轨 + 节点**：

| 节点 | 含义 |
|---|---|
| 空心圆 | 思考（灰色，弱化） |
| 实心圆 | 动作（蓝） |
| 勾 | 结果（绿） |
| 叹号 | 错误（红），`isError` 与 `kind` 任一说错就算错 |
| 呼吸圆点 | 还在执行，后面跟骨架条 |

**步骤不再藏在「日志 N」后面。** 这是这次改动里唯一一处**改掉了原有设计**：之前为了面板安静，把运行过程收在菜单里，结果是「现在到哪一步」永远隔一次点击。删掉 `_showLogs`、菜单里的日志项、结果条上的日志按钮，`_SheetAction` 只剩 `close`。

**目标气泡**：做了又删。运行栏本来就显示目标，留着等于同一句话出现两次，而且任务结束后会把上一句指令留在屏幕上。

**结果条**：一行 —— 左「复制 / 分享」，右「12 步 · 8.4k / 1.2k token」。不再是一堆 pill 加一句游离的用量文字。

### 10.2 列表与设置

新增 `OperonListRow`：56dp 最小高、32dp 图标槽、chevron 固定 18、危险行变红且不给 chevron。设置页的 `_buildSettingRow` 退化成一层薄包装，分组标题、分隔线、圆角一起入档。

历史记录：加 `SiteIcon` 前导、卡片走令牌、动作按钮统一字号（`textStyle: AppType.label`）。

标签页总览：卡片头部从「锁/地球图标 + 灰字」换成 18dp `SiteIcon`，标题 15sp，域名 12sp 灰色；「当前」角标改用 accent tint；关闭按钮 28dp 圆点（热区另算）。

### 10.3 favicon

`lib/services/favicon_service.dart`：

- **只存内存**。图标重启后价值为零；落盘要引入淘汰策略、大小预算和可能过期的缓存，只为省一次请求。
- **两种来源**：WebView 已经下载好的（`getFavicons()` → 取最大尺寸那张 → 再取字节），以及兜底的 `https://host/favicon.ico`。
- **魔数校验**：ICO / PNG / GIF / JPEG / WEBP / SVG。特别是 SVG 只认含 `<svg` 的 —— 首字节是 `<` 的还有服务器返回的 HTML 错误页。
- 失败也缓存（值为 null），同一会话不重复请求。

`SiteIcon` 拿不到图标就画字母，并且字母用主题墨色，不再按品牌色硬编码。

### 10.4 一个真 bug（顺手修的）

`late final AnimationController _x = AnimationController(...)` 是**懒初始化**：如果动画从未启动，第一次触碰它就是 `dispose()` 里 —— 这时元素已经 deactivate，`TickerMode` 查祖先会断言失败。测试一次性爆出 8 个异常。改为在 `initState` 里显式创建（3 处）。

### 10.5 测试

- 更新 4 个用例到新行为：日志不再有开关、结果元信息合并成一行、错误从一开始就可见、窄屏头部只验「不溢出」。
- 新增 `test/ui_components_test.dart`（10 个）：时间线的种类标签 / 运行中不编造结果 / 空态 / 错误配色；favicon 的魔数接受与拒绝、字母兜底；列表行的高度、危险色、长副标题截断。
- 守卫测试的迁移白名单从 4 个文件扩到 14 个。

## 11. 结果能拿走、执行看得见、脚本功能移除

这一批只做三件事，其中两件是产品上的缺口，一件是删减。

### 11.1 结果必须能拿走

以前 `done.data` 落到 `AgentState.extractedData` 之后，出口只有「复制 JSON」和一个塞满 JSON 的弹层。可用户抓 20 条商品，要干的是贴进表格、发给同事、存成 CSV。

新增 `lib/utils/result_export.dart`（纯函数，可单测）：

| 决定 | 理由 |
|---|---|
| 字段取**所有记录的并集**，按首次出现排序 | 只取第一条的键，会让"最后一条才有 `price`"整列静默消失 |
| 缺值是**空格子**，不是短一行 | 短一行会把后面所有列错位 |
| 嵌套对象/数组**保留为紧凑 JSON** | 表格画不出树，丢掉就是丢数据 |
| CSV 前置 UTF-8 BOM、CRLF | 不加 BOM，Excel 打开中文是乱码；要 CSV 的人就是在用 Excel |
| 文件名 `operon-20261115-1430.csv` | 按名排序即按时间排序，多次导出不互相覆盖 |

面板上的数据卡改成一个动作行：**表格 / CSV / 分享**（复制 JSON 留在卡头）。`ExtractedDataSheet` 重写成「表格 / JSON」双视图：表格给"抓对了吗"，JSON 给"模型原话是什么"，两者都从同一张 `ExportTable` 生成，所以卡上的条数、表里的行数、CSV 里的行数不可能对不上。超过 200 行只画 200 行，但**写出全部**，页脚写明"导出 CSV 取全部 N 行"。

`_dataSummary` 多了一句「有缺列」：空单元格读起来像"页面本来就没有"，用户需要知道那是页面的答案还是模型的遗漏。

### 11.2 执行要看得见

幽灵光标只说"这里发生了点什么"，用户真正的问题是"它在弄哪一个"。

- 新增 `lib/control/protocol/gesture.dart` 的 `GestureTarget`：落点 + **元素框** + 名字。框在 `_actionablePoint` 通过四检之后、派发之前由控制层给出，所以描边永远不会指向事件没有落到的地方；被拒绝的动作也画不出框。
- `ControlPort.onGesture` 从 `(x, y, label)` 改成 `(GestureTarget)`，一路透传到 `GestureOverlay`：光标照旧滑动，另加一圈描边——从框外 6px 收进到精确位置，然后淡出。
- 缩放同一处换算：CSS 像素 × 页面 `getZoomScale()`。

没做的两件，理由：

- 面板默认高度**已经是 0.6**（§27.8 就改了），这一批没动。
- **handoff 时压暗页面**没有做：`CaptchaInfo` 只有类型和证据，没有几何信息，压暗却不指出验证码在哪，等于让用户在暗屏上找东西；而验证码本身是要用户看清才能过的。

已知边界：iframe 内元素的四边形是**相对于该 frame 视口**的，描边会落在 frame 的原点附近。光标本来就有同样的限制，这次没有加重，要修得先做 frame 坐标合成。

### 11.3 删除「用户脚本」

理由和删语音、删宏是同一条：**没法在不撒谎的前提下描述清楚**。一个能在已登录页面执行任意 JS 的入口，与"动作由层派发、永不 `eval`"的整个安全叙事直接冲突，而它服务的是极小一撮人。

删除：`models/user_script.dart`、`services/user_script_service.dart`、`views/settings/user_scripts_page.dart`、`views/settings/user_script_sheets.dart`、`LlmService.generateUserScript`（连同那段"写油猴脚本"的系统提示词）、设置页与底栏菜单入口、每次 `onLoadStop` 的注入调用、对应的 README 描述与测试。

### 11.4 定时任务：不做

讨论过「App 没打开也能跑」的三档做法（补跑 / 前台服务 / exact alarm）。结论是不做：真定时在国产 ROM 上是玄学，做半套会换来一个解释不清的失败模式。模板化重跑（`GoalHandoff` 那条路）留在以后再说。
